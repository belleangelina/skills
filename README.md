# skills

个人使用的 Codex Skills 集合。

## 包含的 Skills

- `alcor-remote-workspace`：为 Windows SMB 映射的 Alcor 工作区分流本地与 SSH 操作。
- `browser-timeout-guard`：检查并修复 Codex Chrome 插件的超时补丁。
- `debugging`：定位和修复 Bug。
- `grilling`：围绕复杂或有歧义的需求追问，直到方案达成共识。
- `remote-device-validation`：规划和执行嵌入式 Linux 设备的远程验证。
- `windows-docx-rendering`：在 Windows 上安全调用 LibreOffice 渲染和检查 DOCX。

## 使用

将需要的 Skill 目录复制或克隆到 Codex Skills 目录：

```text
~/.codex/skills/
```

每个 Skill 的具体触发条件和使用说明见对应目录中的 `SKILL.md`。
